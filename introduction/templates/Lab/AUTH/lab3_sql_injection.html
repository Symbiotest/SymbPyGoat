💀 How SQL Injection Works

Vulnerable Query Structure:

SELECT * FROM users WHERE username = '[INPUT]' AND password = '[INPUT]'

Injected Query:

SELECT * FROM users WHERE username = 'admin' AND password = '' OR '1'='1'

The injection makes the WHERE clause always true, bypassing authentication.

🛡️ Prevention Techniques
  • Parameterized Queries: Use prepared statements
  • Input Validation: Whitelist and sanitize inputs
  • Stored Procedures: Use properly written stored procedures
  • ORM Frameworks: Use Object-Relational Mapping tools
  • Least Privilege: Database user with minimal permissions
📝 Vulnerable vs Secure Code Examples
❌ Vulnerable Code:
# String concatenation (VULNERABLE)
query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
cursor.execute(query)
✅ Secure Code:
# Parameterized query (SECURE)
query = "SELECT * FROM users WHERE username = %s AND password = %s"
cursor.execute(query, (username, password))
🎯 Attack Impact and Scenarios
🔓 Authentication Bypass

Access any user account without knowing the password

📊 Data Extraction

Extract sensitive information from the database

💣 Data Manipulation

Modify, delete, or corrupt database contents

Common Injection Types:
  • Boolean-based: ' OR '1'='1

  • Time-based: ' OR SLEEP(5)--
  • Error-based: ' AND EXTRACTVALUE(1, CONCAT(0x7e, version(), 0x7e))--
