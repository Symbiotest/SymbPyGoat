🎯 Learning Objectives
  • Understand why plain text password storage is dangerous
  • Learn about password hashing and salting
  • Recognize the impact of database breaches
  • Practice identifying this vulnerability in code
🛡️ Secure Implementation
  • Use bcrypt, Argon2, or scrypt for password hashing
  • Always salt passwords before hashing
  • Never store passwords in reversible formats
  • Implement proper password policies
Example: password_hash = bcrypt.hashpw(password, bcrypt.gensalt())
🔍 Exploitation Exercise
Try the following:

  3. Try logging in with different users using the exposed passwords
  4. Consider what would happen if an attacker gained database access
Impact Assessment: In a real attack scenario, this vulnerability would allow attackers to:
  • Immediately access all user accounts
  • Use credentials on other sites (credential reuse attacks)
  • Identify weak passwords for targeted attacks
  • Compromise administrative accounts
