Vulnerable Authentication Service - Educational Security Labs

⚠️ Educational Warning: These labs contain intentional security vulnerabilities. They are designed for cybersecurity education and should NEVER be used in production environments.

OWASP Top 10 - A07:2021 Identification and Authentication Failures

This comprehensive authentication service demonstrates multiple critical vulnerabilities that occur when application functions related to authentication and session management are implemented incorrectly, allowing attackers to compromise passwords, keys, or session tokens, or to exploit other implementation flaws to assume other users' identities temporarily or permanently.

Available Laboratory Exercises

🔓 Lab 1: Plain Text Password Storage

Vulnerability: Passwords stored without encryption or hashing

Learning Objective: Understand the critical importance of proper password hashing

Attack Vector: Database compromise reveals all user passwords

Start Lab 1
🎯 Lab 2: Session Fixation Attack

Vulnerability: Sessions not regenerated after authentication

Learning Objective: Learn proper session lifecycle management

Attack Vector: Attacker provides session ID before user authentication

Start Lab 2
💉 Lab 3: SQL Injection Authentication Bypass

Vulnerability: Authentication queries vulnerable to SQL injection

Learning Objective: Understanding parameterized queries and input validation

Attack Vector: Malicious input bypasses authentication logic

Start Lab 3
🎲 Lab 4: Predictable Password Reset Tokens

Vulnerability: Reset tokens generated using weak algorithms

Learning Objective: Cryptographically secure random token generation

Attack Vector: Token prediction enables unauthorized account access

Start Lab 4
🕵️ Lab 5: Username Enumeration

Vulnerability: Information disclosure through authentication responses

Learning Objective: Consistent error messaging and timing considerations

Attack Vector: Response analysis reveals valid usernames

Start Lab 5

🎯 Learning Objectives

  • Understand common authentication vulnerabilities
  • Learn to identify security flaws in authentication systems
  • Practice exploitation techniques in a safe environment
  • Develop secure authentication implementation skills

🛡️ Mitigation Strategies

  • Implement proper password hashing (bcrypt, Argon2)
  • Use cryptographically secure session management
  • Apply input validation and parameterized queries
  • Implement rate limiting and account lockout
  • Use consistent error messages and timing
🔗 API Testing Endpoints

For advanced testing, the following API endpoints are available:

  • POST /auth-service/api/authenticate - Test authentication methods
  • POST /auth-service/api/reset-token - Generate password reset tokens
  • GET /auth-service/api/session-info - View session information
