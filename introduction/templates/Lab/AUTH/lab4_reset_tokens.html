💀 How Token Prediction Works

Weak Token Generation Patterns:

  • Sequential: reset_[user_id]_[timestamp]
  • Predictable Hash: md5(email + timestamp)
  • Weak Random: random.randint(100000, 999999)
  • Partial Timestamp: [user_id][last_4_digits_time]

Attack Process:

  1. Analyze multiple reset tokens for patterns
  2. Identify generation algorithm
  3. Predict tokens for target users
  4. Use predicted tokens for unauthorized password resets
🛡️ Secure Token Generation

Cryptographically Secure Methods:

  • CSPRNG: Cryptographically secure pseudo-random number generator
  • UUID4: Random UUID generation
  • Secrets Module: Python's secrets.token_urlsafe()
  • Crypto Libraries: Platform-specific secure random

Best Practices:

  • Minimum 32 bytes of entropy
  • Short expiration time (15-30 minutes)
  • Single-use tokens
  • Rate limiting on reset requests
  • Log suspicious activities
📝 Vulnerable vs Secure Code
❌ Vulnerable Code:
# Predictable token generation
import time
user_id = str(user.id)
timestamp = str(int(time.time()))
token = f"reset_{user_id}_{timestamp}"

# Weak hash
token = hashlib.md5(f"{email}{timestamp}".encode()).hexdigest()[:16]
✅ Secure Code:
# Cryptographically secure token
import secrets
token = secrets.token_urlsafe(32)

# Or using UUID4
import uuid
token = str(uuid.uuid4())
